# Telegram Message Cleaner
Инструмент для массового удаления сообщений и снятия реакций в Telegram с фильтрацией по времени и типам чатов

## Возможности

- Сканирование по типам чатов: личные сообщения, группы, супергруппы, публикации в каналах
- Конкретные чаты по username или ID
- Фильтрация по диапазону дат
- Вайтлист чатов и сообщений
- Просмотр найденных чатов перед удалением с возможностью исключить отдельные
- Снятие своих реакций с теми же фильтрами, отдельно или вместе с удалением сообщений
- Пакетное удаление с настраиваемым темпом
- Вход по QR-коду, если код из Telegram не приходит
- Завершение сессии прямо из меню
- Автоматическая обработка FloodWait

## Установка

```bash
git clone https://github.com/bells-ring/telegram-message-cleaner
cd telegram-message-cleaner
pip install telethon
python script.py
```

При первом запуске можно войти по QR-коду (Настройки → Устройства → Подключить устройство) или по номеру телефона. Для QR в консоли нужен `pip install qrcode`, без него скрипт покажет ссылку.

## Использование

Сначала скрипт спрашивает, что делать:

```
Что делаем:
  1 - удалить сообщения
  2 - удалить реакции
  3 - удалить сообщения и реакции
  4 - выход
  5 - завершить сессию удалятора и выйти
```

Пункты 1-3 дальше работают одинаково: меню с типами чатов, даты, список найденного, исключения и подтверждение.

```
Что сканируем:
  1 - личные сообщения
  2 - малые группы
  3 - супергруппы
  4 - публикации от имени каналов
  5 - конкретные чаты

Фильтр по датам UTC (Enter - пропустить):
  Не раньше  (DD.MM.YYYY [HH:MM]):
  Не позже   (DD.MM.YYYY [HH:MM]):
```

После сканирования показывает найденные чаты. Для реакций вместо `сообщ.` стоит `реакц.`, а в режиме 3 показаны оба числа:

```
  1.    523 сообщ.  id:-1001234567890  @example  Название чата
  2.     41 реакц.  id:987654321  Имя Фамилия
  3.     12 сообщ. +   30 реакц.  id:-1009876543210  Другой чат
```

Можно исключить чаты перед удалением, введя их номера через запятую.

### Реакции

Скрипт снимает только ваши реакции. Если в режиме 3 на вашем сообщении стоит ваша же реакция, она исчезнет вместе с сообщением и отдельно не считается. Чужие реакции на ваших сообщениях остаются до удаления самих сообщений.

### Завершение сессии

Пункт 5 просит подтверждение, завершает сессию в Telegram и удаляет `session.session`. Для следующего запуска нужен новый вход. Так на диске не остаётся файла, с которым можно зайти в аккаунт без кода.

## Конфигурация

Все настройки в `config.ini`:

- `api_id`, `api_hash` - получить на [my.telegram.org/apps](https://my.telegram.org/apps), по умолчанию работают публичные
- `batch` - количество сообщений за один запрос (по умолчанию 100)
- `delay` - пауза в секундах между батчами (по умолчанию 1.2)
- `react_delay` - пауза между снятием реакций, по умолчанию как `delay`
- `scan_delay` - пауза между страницами истории при сканировании (по умолчанию 0.3)
- `chats`, `messages`- username, ID чатов и ссылки для внесения в вайтлист

## Ограничения

1. Сообщения из чатов, в которых вы не состоите в момент инициализации скрипта, удалить нельзя. 
2. Личные сообщения сканируются медленнее групп из-за ограничений API Telegram.
3. Поиска по своим реакциям в API нет, поэтому скрипт перебирает всю историю чата. Сужайте даты, иначе будет долго.
4. Реакции за звёзды (платные) снять нельзя.
