# Telegram Message Cleaner
Инструмент для массового удаления сообщений в Telegram с фильтрацией по времени и типам чатов

## Возможности

- Сканирование по типам чатов: личные сообщения, группы, супергруппы, публикации в каналах
- Конкретные чаты по username или ID
- Фильтрация по диапазону дат
- Вайтлист чатов и сообщений
- Просмотр найденных чатов перед удалением с возможностью исключить отдельные
- Пакетное удаление с настраиваемым темпом
- Автоматическая обработка FloodWait

## Установка

```bash
git clone https://github.com/bells-ring/telegram-message-cleaner
cd telegram-message-cleaner
pip install telethon
python script.py
```

Во время первого запуска скрипт попросит номер телефона и код из Telegram.

## Использование

Скрипт покажет меню с типами чатов:

```
Что сканируем:
  1 - личные сообщения
  2 - малые группы
  3 - супергруппы
  4 - публикации от имени каналов
  5 - конкретные чаты

Фильтр по датам UTC (Enter - пропустить):
  Не раньше  (DD.MM.YYYY [HH:MM]):
  Не позже   (DD.MM.YYYY [HH:MM]):
```

После сканирования показывает найденные чаты:

```
  1.    523 сообщ.  id:-1001234567890  @example  Название чата
  2.     41 сообщ.  id:987654321  Имя Фамилия
```

Можно исключить чаты перед удалением, введя их номера через запятую.

## Конфигурация

Все настройки в `config.ini`:

- `api_id`, `api_hash` - получить на [my.telegram.org/apps](https://my.telegram.org/apps), по умолчанию работают публичные
- `batch` - количество сообщений за один запрос (по умолчанию 100)
- `delay` - пауза в секундах между батчами (по умолчанию 1.2)
- `chats` - username и ID чатов для пропуска
- `messages` - ссылки на конкретные сообщения, которые не удалять

## Ограничения

1. Сообщения из чатов, в которых вы не состоите в момент инициализации скрипта, удалить нельзя. 
2. Личные сообщения сканируются медленнее групп из-за ограничений API Telegram.
